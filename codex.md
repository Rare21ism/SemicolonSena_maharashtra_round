IMPORTANT:

THIS IS A STRUCTURAL REDESIGN.

DO NOT JUST CHANGE THE COLORS.
DO NOT JUST CHANGE THE FONT.
DO NOT JUST CHANGE THE BACKGROUND.

The existing functionality stays.
The visual architecture changes.

============================================================
# 1. WHAT WE ARE TRYING TO ACHIEVE
============================================================

Roundtable is:

A live group conversation captioning system where multiple nearby devices contribute audio so that people can follow a conversation through live, speaker-aware captions.

The product's core idea is:

MANY VOICES
        ↓
ONE CONVERSATION
        ↓
EVERYONE CAN FOLLOW

The UI should make this concept visually obvious.

The final interface should feel like:

editorial design
+
accessibility product
+
real-time communication
+
voice interaction
+
premium product design

It should NOT feel like:

generic AI SaaS
generic dashboard
generic meeting app
generic transcription tool
generic component-library template
generic hackathon project

# 2. DESIGN REFERENCES
============================================================

------------------------------------------------------------

Use:

- oversized typography

- asymmetric composition
- large visual blocks
- thin borders
- restrained palette

------------------------------------------------------------

Use the principle that the transcript is the product.

The live conversation should be visually important.

Not:

- controls
- cards
- technical information
- settings

The transcript should become the hero of the actual meeting experience.

------------------------------------------------------------
REFERENCE C — ACCESSIBILITY-FIRST CAPTIONS
------------------------------------------------------------

Captions should be:

- immediately readable
- high contrast
- large enough
- low distraction
- glanceable
- comfortable over long periods

Do NOT sacrifice usability just to make the UI look fashionable.

Accessibility IS the product.

------------------------------------------------------------
REFERENCE D — VOICE AS A VISUAL IDENTITY
------------------------------------------------------------

Create one distinctive visual metaphor for:

- listening
- speaking
- silence
- voice activity

Do not simply use a generic waveform because every AI product does.

Create something specific to Roundtable.

# 4. THE ROUND TABLE VISUAL LANGUAGE
============================================================

Create a visual metaphor around:

VOICE → PEOPLE → CONVERSATION.

Do NOT literally draw a table everywhere.

Instead create a visual system based on:

- circles
- relationships
- flow
- voice activity
- conversation
- timing
- presence

This visual system should appear throughout the product.

For example:

MIC SETUP:
voice → identity

MEETING:
speaker → caption

HISTORY:

These should feel like parts of ONE design system.

# 9. CREATE A "CAPTION RIVER"
============================================================

Instead of making the transcript a conventional vertical chat list:

Create a visual "river" of conversation.

Current speech:

- large
- high contrast
- visually alive

Older speech:

- smaller
- quieter
- less prominent

The conversation naturally moves through time.

Think:

current speech = now
recent speech = memory
older speech = history

Do not make it look like WhatsApp.
